# BNCC Cadet Hub

আমি একটি Mobile app তৈরি করতে চাচ্ছি । 
আমি BNCC Naval Wing এর জন্য একটি secure, user-friendly management app বানাতে চাই, যেখানে ক্যাডেট ম্যানেজমেন্ট, ডকুমেন্ট ম্যানেজমেন্ট, ইকুইপমেন্ট ইনভেন্টরি, অফিসিয়াল লেটার ম্যানেজমেন্ট, অ্যাটেনডেন্স সিস্টেম, রিপোর্ট জেনারেশন, রোল-বেসড অথেন্টিকেশন, সুন্দর ড্যাশবোর্ড, সার্চ ও ফিল্টার, নোটিফিকেশন, ব্যাকআপ, অফলাইন সাপোর্ট, এবং ভবিষ্যতে QR কোড ও ডিজিটাল সিগনেচার মতো ফিচার থাকবে।
